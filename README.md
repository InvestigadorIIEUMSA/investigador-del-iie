# INVESTIGADOR DEL IIE

Portal académico personal de Roberto Aguilar Gómez, preparado como sitio web independiente.

## Publicación gratuita recomendada

- Repositorio: GitHub.
- Alojamiento: Cloudflare Pages.
- Cuenta de administración: `investigadoriieumsa@gmail.com`.
- Comando de compilación: ninguno.
- Directorio de publicación: `/` (raíz del repositorio).

## Archivos principales

- `index.html`: estructura y textos del portal.
- `styles.css`: diseño, colores y adaptación para teléfonos.
- `script.js`: menú móvil y buscador interno.
- `assets/`: imágenes y favicon.

## Actualizar contenidos

1. Conservar una copia de respaldo.
2. Editar `index.html` o solicitar a ChatGPT el bloque exacto que debe modificarse.
3. Subir el cambio a GitHub.
4. Cloudflare Pages publicará automáticamente la nueva versión.

## Panel privado

No se incluyó una contraseña simulada en esta versión estática. Un panel real requiere autenticación y almacenamiento seguro; se incorporará como segunda etapa mediante servicios gratuitos de Cloudflare. Hasta entonces, los cambios se realizarán en GitHub con la ayuda de ChatGPT.

## Buscadores

Después de definir la dirección pública se añadirán `sitemap.xml`, `robots.txt`, la dirección canónica y la verificación de Google Search Console con el dominio definitivo.
